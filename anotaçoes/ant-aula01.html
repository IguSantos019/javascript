Váriaveis e tipos primitivos

Váriaveis

Uma váriavel nada mais é do que um espaço de locação na memória do computador. Para declarar uma váriavel temos a opção var ou let. Seguimos o exemplo:

var n1 = 5
var n2 = 8
ou
let nome = 'Igor'
let idade = 22
let profissao = "Garçom"

Esse var é a tag para declarar que o código é uma variável, a declaração da variável está em azul claro, o sinal de = significa que o próximo valor irá receber o valor.

Identificadores

Nas declarações de variáveis temos que seguir algumas regras que são basicamente, começar com letras (não é possível começar com números) pode conter números depois da primeira letra, aceita símbolos e acentos nas declarações, não pode conter espaços entre as letras, não pode ser utilizado palavras reservadas, por exemplo var ou function e etc..

Para uma melhor organização e controle podemos usas essas dicas

Tratamento de dados

Para tratarmos os dados de uma váriavel é bem simples já que a própria váriavel já armazena o seu conteúdo, o que podemos fazer é usar esses dados apenas chamando essa variável, por exemplo:
var n1 = window.prompt('Digite um número qualquer')
window.alert(n1)

Para fazermos uma soma por exemplo não é tão simples quanto 1 + 1 já que o sinal de + significa uma concatenação (juntar um com outro). Para isso precisamos declarar o número como o tipo number, vejamos o exemplo a seguir:
var n1 = window.prompt('Digite um número qualquer')
var n2 = window.prompt ('Digite outro número')
var soma = Number(n1) + Number(n2)
window.alert(soma)
